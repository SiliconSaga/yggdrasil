# Yggdrasil

Yggdrasil is the workspace root for the [SiliconSaga](https://github.com/SiliconSaga) ecosystem — a collection of projects spanning a homelab Kubernetes platform, game services, and developer tooling.

This site hosts documentation for the workspace itself, the components it orchestrates, and [Guardian Driven Development (GDD)](gdd/index.md) — a methodology for human-AI collaboration that grew out of this project.

## What's Here

### [Yggdrasil Workspace](ecosystem-architecture.md)
The original homelab and platform docs — ecosystem architecture, dev setup, the `ws` CLI, multi-repo workflow, and agent security patterns.

### [Guardian Driven Development](gdd/index.md)
A methodology for human-AI collaboration in software projects. GDD wraps existing practices (BDD, TDD, code review) in structured guidance that adapts to who's working, what role they're filling, and how much time they have. Includes the SecondBrain shared thinking space, trust verification, and a self-improving audit loop.

### [Getting Started](getting-started/index.md)
How to get set up — whether you're here to contribute to SiliconSaga components or to try GDD in your own projects.

### [GDD Samples](gdd/samples/index.md)
GDD in action — session transcripts, SecondBrain file samples, and cross-workspace collaboration examples showing how the methodology works in practice.
