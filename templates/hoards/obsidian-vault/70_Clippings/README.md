# Clippings

Raw imported content — web clippings, paperless dumps, audio transcripts, anything ingested from outside the vault before refinement.

Distinct from `30_Resources/`, which is for curated / refined reference material. Clippings start here; if they earn a permanent place they get moved (and usually rewritten) into `30_Resources/`.

## Capture sources

- **Obsidian Web Clipper** (browser extension) — destination set to this folder in extension settings. Configure highlights to *replace* page content rather than append, so the saved note is just the meaningful excerpt.
- Manual paste-in of pages, articles, transcripts.

## Conventions

- New clippings arrive pre-formed (Web Clipper writes its own frontmatter and structure on paste; manual pastes go in raw). No Templater template — clippings aren't a hand-authored note shape.
- Move to `30_Resources/` once a clipping has been read, distilled into your own words, or wikilinked into the rest of the vault.
- Stale clippings (months old, never re-read) get archived to `40_Archive/` rather than left to rot here.
