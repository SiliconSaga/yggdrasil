# GDD Zen Mode

A behavior modifier for deep focus sessions. Full ceremony, thorough work,
and proactive maintenance. For when you have time to do things right.

## When to Use

- Dedicated work sessions (1+ hours)
- Saturday morning deep dives
- The user says "let's do this properly" or "I have time today"
- When accumulated concerns or observations need attention

## Behavior Modifications

| Activity | Without Zen | With Zen |
|----------|------------|----------|
| Orientation | Standard | Full — review all SecondBrain content, proactively suggest housekeeping if stale |
| Brainstorming | Normal flow | Full brainstorming skill with all steps |
| Code review | Standard | Comprehensive — check all findings, no shortcuts |
| Commits | Standard messages | Detailed messages with context |
| Housekeeping | On request | Proactively suggest if audit is stale |
| Side items | Note and continue | Triage into issues for later (@creating-github-issues) |
| Documentation | Update what's touched | Consider broader doc updates |
| Testing | Run what's relevant | Run full test suite, check coverage |

## Deep Work Patterns

Zen mode encourages:

- **End-to-end completion** — finish what you start, don't leave half-done work
- **Audit accumulated debt** — review SecondBrain observations, process concerns
- **Triage deferred work** — items noted as "deal with later" get filed as
  issues or addressed
- **Comprehensive reviews** — don't skip the hard parts of code review
- **Reflective practice** — after completing work, reflect on what went well
  and what was friction

## Composition

- **Zen + Mentoring:** Deep work with thorough teaching. The most
  comprehensive mode combination — full explanations, full ceremony.
- **Zen + Autonomous:** AI works independently with full diligence. Detailed
  logging, comprehensive tests, thorough PR descriptions.

## What This Mode Does NOT Do

- Force unnecessary ceremony on simple tasks
- Prevent the user from speeding up ("actually let's skip brainstorming here")
- Require a minimum session length
- Block progress with excessive review — thoroughness serves the work, not
  the process
